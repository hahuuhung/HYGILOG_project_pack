# Handover

## Handover Objective
A competent new engineer should be able to:
- clone repository
- configure environment
- run backend
- run web
- run mobile
- understand architecture
- understand RBAC
- deploy
- troubleshoot common issues

## Required Handover Topics
1. Architecture
2. Local setup
3. Deployment
4. Authentication
5. RBAC
6. Tenant isolation
7. Database
8. Web/mobile sync
9. AWS Amplify
10. Cloudflare
11. NFC
12. Troubleshooting
13. Git workflow
